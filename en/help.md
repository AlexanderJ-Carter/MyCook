# Help

Welcome to **MyCook** — a unified kitchen for Chinese home cooking recipes.

> **Note:** Most recipe content is in Chinese (from open-source upstream projects). The site UI can be switched to English via the **English** button in the top navigation.

## Find a recipe

| Goal | How |
|------|-----|
| By cooking style | [CookLikeHOC](/cooklikehoc/炒菜/README) — stir-fry, braise, soup, etc. |
| By ingredient | [HowToCook](/howtocook/dishes/vegetable_dish/西红柿炒鸡蛋) — veg, meat, breakfast… |
| By photo | [HowToCook Images](/howtocook-images/) |
| By difficulty | Home page → difficulty cards (0–2 ★ to 6+ ★) |
| By what you have | Home → **Fridge** — pick ingredients or spin random |

Press **Ctrl+K** (or **/**) anywhere to search by dish name.

## Recipe page toolbar

On any recipe page, the floating toolbar offers:

- **Save** — bookmarks in your browser
- **Link / Share** — copy URL or native share
- **Random** — jump to another recipe
- **Video** — search Bilibili for tutorials
- **AI** — copy recipe + prompt for ChatGPT, Claude, etc. (no API key needed)
- **Print** — printer-friendly layout
- **Timer** — cooking countdown with notifications

## Weekly meal plan

On the home page, **Meal Plan** lets you assign recipes to Mon–Sun. Data stays in **localStorage** only — nothing is uploaded.

## Install as app (PWA)

Use your browser’s “Install” or “Add to Home Screen” option for offline access and faster launch.

## For developers & AI agents

See [/en/ai-agents](/en/ai-agents) for MCP, OpenAPI, and Agent Skills.

## Privacy

Favorites, meal plans, and preferences are stored **only in your browser**. MyCook does not require an account.
